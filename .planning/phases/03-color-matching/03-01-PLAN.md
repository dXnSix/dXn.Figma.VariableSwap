2. **colorsMatch function:**
   - Takes two RGB values and optional tolerance parameter (defaults to COLOR_TOLERANCE)
   - Returns true if all three channels (r, g, b) are within tolerance
   - Use Math.abs() for difference calculation
   ```typescript
   function colorsMatch(color1: RGB, color2: RGB, tolerance: number = COLOR_TOLERANCE): boolean {
     return (
       Math.abs(color1.r - color2.r) < tolerance &&
       Math.abs(color1.g - color2.g) < tolerance &&
       Math.abs(color1.b - color2.b) < tolerance
     );
   }
   ```

3. **tryParseColor function:**
   - Takes a source string, returns RGB | null
   - Quick check: if string doesn't start with '#' or 'rgb' (case-insensitive), return null
   - Use figma.util.rgba() to parse valid color strings
   - Return { r, g, b } without alpha (SolidPaint.color is RGB not RGBA)
   - Wrap in try-catch, return null on parse failure
   ```typescript
   function tryParseColor(source: string): RGB | null {
     const trimmed = source.trim().toLowerCase();
     if (!trimmed.startsWith('#') && !trimmed.startsWith('rgb')) {
       return null;
     }
     try {
       const rgba = figma.util.rgba(source);
       return { r: rgba.r, g: rgba.g, b: rgba.b };
     } catch {
       return null;
     }
   }
   ```

These utilities provide:
- COLR-04: Format normalization (figma.util.rgba handles #FFF -> full RGB)
- COLR-05: Tolerance-based comparison for floating-point precision

Modify processNode to check ALL fills and strokes, matching by variable name OR hardcoded color value.

**Key insight from research:** The current implementation only loops through bound variables. It needs to loop through all fills/strokes and determine for each one whether to match by variable name (if bound) or color value (if hardcoded).

**Implementation approach:**

1. **Add findMatchingNewVariable helper function** that encapsulates the matching logic:
   - Takes: fill (SolidPaint), fillIndex, node, colorMapping
   - Returns: Promise<string | null> (new variable name or null)
   - Logic:
     a. Check if fill is bound to variable: `node.boundVariables?.fills?.[fillIndex]`
     b. If bound: get variable name, look up in colorMapping (existing behavior - COLR-01)
     c. If NOT bound (hardcoded): iterate colorMapping entries, try to parse each 'old' key as color, compare with fill.color using colorsMatch
   - Priority: variable name match first, then color value match

2. **Refactor processNode:**
   - Remove the loop over `variables` (from getNodeVariables)
   - Add new loop that iterates over fills directly:
     ```typescript
     if ('fills' in node && Array.isArray(node.fills)) {
       const mutableFills = [...node.fills];
       for (let i = 0; i < node.fills.length; i++) {
         const fill = node.fills[i];
         if (fill.type !== 'SOLID') continue;

         const newVariableName = await findMatchingNewVariable(fill, i, node, colorMapping);
         if (newVariableName) {
           const newVariable = await findVariableByName(newVariableName);
           if (newVariable) {
             mutableFills[i] = figma.variables.setBoundVariableForPaint(fill, 'color', newVariable);
             changesMade++;
           } else {
             figma.notify(`Variable "${newVariableName}" not found`, { error: true });
           }
         }
       }
       node.fills = mutableFills;
     }
     ```
   - Add similar loop for strokes (same pattern, different property names)

3. **The findMatchingNewVariable function:**
   ```typescript
   async function findMatchingNewVariable(
     fill: SolidPaint,
     fillIndex: number,
     node: SceneNode,
     colorMapping: { [key: string]: string }
   ): Promise<string | null> {
     // Priority 1: Match by bound variable name (COLR-01)
     if ('boundVariables' in node) {
       const boundVariable = node.boundVariables?.fills?.[fillIndex];
       if (boundVariable) {
         const variable = await figma.variables.getVariableByIdAsync(boundVariable.id);
         if (variable && colorMapping[variable.name]) {
           return colorMapping[variable.name];
         }
       }
     }

     // Priority 2: Match by hardcoded color value (COLR-02, COLR-03)
     for (const [oldSource, newVariable] of Object.entries(colorMapping)) {
       const sourceColor = tryParseColor(oldSource);
       if (sourceColor && colorsMatch(fill.color, sourceColor)) {
         return newVariable;
       }
     }

     return null;
   }
   ```

4. **Create analogous findMatchingNewVariableForStroke function** for strokes (checks `node.boundVariables?.strokes?.[strokeIndex]`)

5. **Keep getNodeVariables function** for now (may be useful for debugging/logging), but processNode no longer depends on it for matching logic.

6. **Console logging:** Keep log statements for debugging but simplify them to show what matched (variable name or color value).
